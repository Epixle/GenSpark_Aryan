FINANCE TRACKER

The finance tracker uses a CSV file to keep track of the different transactions the user
deals with (spending or incoming). There are different functions to add a transaction, view
all transactions, show current balance, get a category breakdown of the spendings grouped
together, and get a monthly summary of the transactions grouped by month. There are also
some helper functions that deal with reading and writing to the CSV.


HOW TO RUN

Make sure Transactions.csv is in the same level and run `python Finance_Tracker.py`.


LIMITATIONS

There is currently no way to edit or delete a transaction, only add and view them.
The transactions are also limited to dollars, not international currency or exchanges.
